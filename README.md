# 孕期记录日历

一个单文件、零依赖的孕期记录页面：日历形式，温馨粉色调，标注每周周次、每次产检，并支持每天写备注。

👉 在线访问：https://apzhouyx.github.io/pregnancy-tracker/

## 功能

- **孕周追踪** — 顶部显示当前孕周（周+天）、第几周、距预产期天数，40 周进度条按早/中/晚三段分色
- **月历视图** — 每格显示日期、孕龄（`8w0d`），每周首日自动挂「第 N 周」徽章，产检日显示简称标签，有备注的日子右下角有小圆点
- **产检计划** — 按中国孕产期保健标准生成 15 次产检，自动从末次月经推算日期，标明「已完成 / 下次产检 / 待补做」及倒数天数，展开可看当次检查项目，可勾选完成
- **每日备注** — 点日历任意一天即可写多条备注，带「身体 / 心情 / 饮食 / 待办」标签
- **本周要点** — 40 周每周一条孕期提示，随所选日期变化
- **回到今天** — 日历头部按钮 + 右下角悬浮球

## 数据存储

备注和产检勾选状态保存在**浏览器本地**（`localStorage`），不上传服务器，刷新和关机都不会丢。

⚠️ `localStorage` 按站点来源隔离，所以：

- `apzhouyx.github.io` 上的备注 ≠ 本地双击打开 `index.html` 的备注
- 换浏览器、换设备、清理浏览数据 → 备注会丢，重要内容请另存

## 修改与重新发布

页面就是根目录的 `index.html`，无构建步骤：

1. 改 `index.html`
2. 提交并推送：

   ```bash
   git add index.html
   git commit -m "update"
   git push
   ```

3. 等 1–2 分钟，Pages 自动重新部署

### 改末次月经

页面右上角可直接改，默认值在 `index.html` 里：

```js
const DEFAULT_LMP = "2026-08-15";
```

改这一行，所有孕周、预产期、产检日期都会重算（首次产检等预置记录也会跟着重算）。

## 计算规则

- 预产期 = 末次月经 + 280 天
- 孕周 = `(今天 − 末次月经) ÷ 7` 的商与余数
- 周次序号 = `商 + 1`（末次月经当天算第 1 周）
- 孕早期 < 14 周，孕中期 14–27 周，孕晚期 ≥ 28 周
